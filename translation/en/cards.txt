# Chapter title cards: the English lettering of the cards shown when a stage
# starts (graphics target 'cards': tools/gfx/cards.py, patch/src/cards.asm;
# notes in docs/workstreams/gfx-chapter-cards.md).
#
# [story N]  the card shown the first time chapter N (1-20) is played
# [area N]   the card shown when a cleared chapter N is played again
#
# Lines of a card:
#   ^text    the heading line (at most one, before the title); it is drawn
#            in screen rows 8-9, and its digits get 2-px strokes like the
#            original chapter numbers
#   text     the title line (one): screen rows 10-11
#   same N   this card is card N of the same set (one shared record)
#
# Every line is centred and drawn in assets/font/title16.txt with the
# original's outline (white ink, dark-blue 1-px outline) and 4-px word gaps.
# The lettering must stay inside the original lettering block (12 x 4 cells,
# screen x 32-127, y 64-95), so a line may be at most 96 px wide with its
# outline: python -m tools.gfx.cards fit measures them. Names follow
# glossary.md and the scenario-map stage labels in ui.txt.
