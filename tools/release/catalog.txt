# Chapter saves for the release package ("Chapter saves" folder next to
# zenobia.exe). Made by `python -m tools.release.catalog` from the
# maintainer's test states (build/states, machine-local) into build/catalog/.
#
# One entry per line: FILE NAME | STATE | INPUT | NOTE
#   FILE NAME  the .sav name in the package
#   STATE      a state in build/states (name without .state) or a path; it
#              must show the scenario map with the popup open on Organize,
#              unless INPUT gets there first
#   INPUT      harness input run before the save, as INPUT@FRAMES (empty:
#              none); the save itself is Data > Save > OK, run by the tool
#   NOTE       what the save holds and what comes next (for the guide)
#
# Every save holds file 1 only, with the hero named Tristan. The states come
# from real play (the only testing aid was enemy HP set to 1 when a battle
# starts); see docs/workstreams/release.md, "Chapter saves".
