# title16: English display font with 11 rows per glyph, for the chapter title
# cards, the intro narration and the title subtitle (white lettering with an
# outline). Original design for this project, drawn pixel by pixel: the letters
# and digits come from the chapter-cards prototype (round 1), the punctuation
# and symbols were added in round 2. Nothing is traced or copied from the game's
# art or from any other font.
# Licence: MIT (the project licence, see LICENSE). The project owner may also
# dedicate it to the public domain (CC0), like vwf8.txt.

# Metrics: capitals and digits use rows 0-8 (cap height 9 px, baseline = row 8).
# Lower case has its x-height in rows 3-8, ascenders from row 0 (t, i and j
# from row 1) and descenders in rows 9-10. Strokes are 1 px wide. The renderer
# adds a 1-px outline (4 or 8 neighbours), so a line is 13 px tall and sits in
# a 16-px band. Character set: the same as vwf8.txt (85 glyphs).
# Notes and width tables: docs/workstreams/gfx-fonts.md.

# Syntax (as in vwf8.txt): '@NAME [advance=N]' starts a glyph, followed by 11
# rows of '#' (ink) and '.' (blank), all of the same width. The advance defaults
# to the width + 1. Names are single characters plus SPACE, ELLIPSIS (the
# ellipsis character) and LQUOTE (the opening double quote). '"' is the closing
# double quote, and the apostrophe glyph also serves as both single quotes.
# A comment line starts with '# ' and must never consist of '#' and '.' only.
