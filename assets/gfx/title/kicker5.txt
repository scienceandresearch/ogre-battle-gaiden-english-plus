# kicker5: small bold capitals for the line above the main title of the title
# screen (5 rows). Original design for this project, drawn pixel by pixel;
# nothing is traced or copied from the game's art or from any other font.
# Licence: MIT (the project licence, see LICENSE).

# Metrics: every glyph uses all 5 rows. Vertical strokes are 2 px wide,
# horizontal strokes 1 row, so the black outline of the title style keeps the
# 1-px counters apart. The title renders the ink in the fire fill and the
# outline and glow of the main title, 1 px between letters
# (tools/gfx/title.py).

# Syntax (as in vwf8.txt): '@NAME [advance=N]' starts a glyph, followed by 5
# rows of '#' (ink) and '.' (blank), all of the same width; the advance
# defaults to the width + 1. A comment line starts with '# ' and must never
# consist of '#' and '.' only.
