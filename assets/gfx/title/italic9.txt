# italic9: thin italic capitals for the subtitle of the title screen (9 rows).
# Original design for this project, drawn pixel by pixel: 1-px strokes on a
# 5x9 grid (I 1 px wide), slanted 1 px every 3 rows (rows 0-2 shifted 2 px
# right, rows 3-5 1 px). Nothing is traced or copied from the game's art or
# from any other font.
# Licence: MIT (the project licence, see LICENSE).

# Metrics: every glyph uses all 9 rows (cap height 9 px, no descenders). The
# advance is the upright width + 3, so letters stand 3 px apart on every row;
# SPACE advance 3 (words 6 px apart). The title draws the ink in amber with a
# brown outline (plane-2 palette 5, tools/gfx/title.py), like the original
# subtitle.

# Syntax (as in vwf8.txt): '@NAME [advance=N]' starts a glyph, followed by 9
# rows of '#' (ink) and '.' (blank), all of the same width. A comment line
# starts with '# ' and must never consist of '#' and '.' only.
